# Sustainable Work Lab

A website for Penn State's Sustainable Work Lab, providing information about research, publications, events, and resources.

## Technologies
- HTML
- CSS
- JavaScript

## Project Structure

- `assets/` – Images and logos
- `css/` – Website styling
- `js/` – JavaScript functionality and data
- `pages/` – Website pages
- `homepage.html` – Main homepage

## Getting Started

1. Clone the repository.
2. Open the project in VS Code.
3. Open `homepage.html` in a browser or using Live Server.
